- Davi pegou uma esfera magica criada quando o mecanismo foi ativado.
- Kael convenceu Nilo a entregar a Caixinha do Ontem para tentar salvar Liora.
  Kael prometeu trazer Eliora de volta, mas essa promessa foi uma mentira usada
  para conseguir a caixa.
- O grupo voltou para a Vila levando uma Caixinha do Ontem e uma esfera magica.
- Connor e Grim foram com Kazuo e Orian ao Acampamento Comunitario. O grupo viu
  o estoque de comida, entrou no galpao dos mapas e liberou o Mapa Mundi.
- Os grupos se reuniram novamente e seguiram para o Campo de Treinamento,
  conforme o treino combinado com Renji.

## Preparacao obrigatoria da Sessao 04

### Recompensas do Treinamento Inicial

Preparar para os cinco protagonistas:

1. Uma arma de dano `1d6` e/ou um escudo/lanca para cada jogador.
2. Um nivel de personagem para cada jogador.
3. Seis itens, um de cada arquetipo, para o grupo escolher e decidir se absorve.
4. Uma habilidade individual para cada protagonista.
5. Um aparelho de traducao simultanea para cada jogador.

### Dispositivos de traducao

- Renji e Kazuo possuem a explicacao e o contexto dos aparelhos.
- Os aparelhos quebrados foram usados para aprender a lingua antiga falada na
  Vila.
- Nilo consertou cinco dispositivos para entregar aos jogadores.
- Cada aparelho entende linguas catalogadas do mundo e permite aos protagonistas
  conversar com NPCs de outras regioes.
- Os protagonistas ja entendem a lingua antiga da Vila por terem absorvido
  acontecimentos da lore local. Essa explicacao continua secreta e nao deve
  entrar no Livro do Jogador antes da revelacao do Mestre.
